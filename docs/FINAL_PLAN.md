# 神秘客平台最终规划确认文档

## 1. 项目定位

神秘客是一个会员制任务商城平台。

用户端主要用于：
- 接任务
- 上传任务进度
- 购买商品
- 积分兑换商品
- 邀请新人
- 申请提现
- 查看钱包和积分
- 使用 VIP 专属商品和任务

后台端主要用于：
- 发布任务
- 上架商品
- 审核任务
- 审核提现
- 管理用户
- 管理积分
- 管理钱包
- 管理邀请
- 管理 VIP
- 风控管理
- 内容运营
- 数据统计

## 2. 权限规则

普通用户和 VIP 用户只能接任务和购买商品。

只有平台管理员可以：
- 发布任务
- 出售商品
- 上架商品
- 审核任务
- 审核提现
- 设置奖励规则
- 设置 VIP 权限
- 管理平台数据

## 3. 核心模块

### 用户系统

- 用户注册
- 用户登录
- 设置密码
- 用户唯一编码
- 用户邀请码
- 邀请二维码
- 自动绑定上级
- 个人资料

### 邀请系统

- 老用户生成邀请二维码
- 新人扫码进入网站
- 注册后自动绑定邀请人
- 邀请奖励进入积分或冻结余额
- 后台可设置奖励规则

### 积分系统

- 注册送积分
- 完成任务送积分
- 购买商品送积分
- 邀请新人送积分
- 积分可兑换商品
- 积分不能提现

### 钱包提现系统

- 可提现余额
- 冻结余额
- 任务押金冻结
- 满 1 元可申请提现
- 每日最多提现 1 次
- 后台人工审核提现

### 商城系统

- 普通商品
- VIP 商品
- 积分商品
- 商品详情
- 订单记录
- 后台商品管理

### 任务系统

- 后台发布任务
- 用户接任务
- 设置完成期限
- 上传任务进度
- 后台审核任务
- 审核通过后发放奖励

### 押金系统

任务可以设置是否需要押金。

押金类型：
- 积分押金
- 余额押金

押金流程：
- 用户接任务时冻结押金
- 审核通过后退还押金并发放奖励
- 超时或恶意提交时，后台可扣除部分或全部押金
- 平台取消任务时，全额退还押金

### VIP 系统

- 后台开通 VIP
- VIP 到期时间
- VIP 专属商品
- VIP 专属任务
- VIP 积分加成

### 聊天系统

第一版先做文字聊天：
- 用户私聊
- 任务聊天
- 未读消息
- 后台查看聊天记录

### 风控系统

- 注册 IP 记录
- 登录 IP 记录
- 提现异常记录
- 邀请异常记录
- 黑名单
- 冻结账号
- 限制提现
- 奖励撤回

- 短信验证码
- 实名认证
- 语音聊天
- 群聊
- 自动风控模型
- 多级返佣
- 原生 APP
- 苹果上架
- 微信登录
- 支付宝登录
- 直播功能

## 6. 技术方案

- 用户端：Vue 3 + Vite
- 后台端：Vue 3 + Vite
- 后端：Node.js + Express
- 数据库：MySQL
- 登录鉴权：JWT
- 文件上传：本地 uploads，后期迁移 OSS/COS
- 聊天：第一版轮询，后期 WebSocket
- 部署：云服务器 + 域名 + HTTPS
